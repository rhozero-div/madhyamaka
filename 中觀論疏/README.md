## 體例要點

- **注疏不注頌。** 疏義與所破兩欄都面對吉藏；青目只在「對頌」出現。
- **一主二附。** 疏義每條必有；所破、對頌有條件才寫。只有疏義一欄是常態。
- **不復述。** 疏文讀者自己會讀，注中不重抄。所補者三：難詞、術語、省略的推理。引原文只限對勘異文或指其跳步，一句即止，不逾二十字。
- **不考據、不中印對比、不代其作答。**
- 篇幅：疏義八十至二百五十字；加所破至四百；加對頌至五百。
