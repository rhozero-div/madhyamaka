# 中觀學 · 印度、中國、日本的中觀傳統

> 从恒河到长安，再到奈良——一条关于「空」的思想线索，走了约一千八百年。

**在线浏览：<https://rhozero-div.github.io/madhyamaka/>**

以大正藏三十部典籍为底本，上溯印度论师的造论与注疏，下及隋唐三论宗的判教与注疏，终至日本南都三论宗的承袭与变形。单文件静态站点，无外部依赖。

## 数据结构

页面只是外壳，正文、注释、术语分三层存放，互不牵连：

| 层 | 位置 | 说明 |
| --- | --- | --- |
| 正文 | `text/<大正藏号>.json` | 按段切分，段落锚点用大正藏官方 `xml:id` |
| 注释 | `annotations/<大正藏号>.json` | 每部文本一个文件 |
| 术语 | `glossary/terms.json` | 全站一份，注文与术语表共用 |
| 渲染 | `assets/reader.css`、`assets/reader.js`、`assets/glossary.js` | 页面只以 `<body data-text="…">` 指定文本，其余由 JSON 的 meta 决定 |

注释锚在「段 id + 起止偏移（`offset`／`end`）+ 所注原文」上，故正文重新切分或换底本时注不会错位。**角标画在所注文字的右端**：整句之注落在句末，句中之词注依次在前，读时先词后句；同一单元内按右端位置编号，右端相同者短注在前。句末串讲则 `offset` 与 `end` 同取该单元止处，`quote` 留空。

正文 JSON 的 `juan` 块是分页单位——《中观论疏》按卷，《金刚经》按分；顶层 `front: true` 者首屏先列目次，`unit: "分"` 供界面措辞取用。偈颂另作 `verse` 块，`t` 内以换行分句，页上低两格、不缩首行。段 id 一仍大正藏 `xml:id`（如 `pT08p0748c2001`），故锚点与本仓库无关，换页面不改数据。

### 注文分三截

一条注可分「原义 / 观义 / 串讲」三栏，另附「所引」，页上各带小标签显示：

```json
{ "id": "…", "para": "pT08p0848c0601", "offset": 17, "end": 19, "quote": "五蘊",
  "parts": [ {"k": "原义", "t": "…"}, {"k": "观义", "t": "…"}, {"k": "串讲", "t": "…"} ],
  "src": [ {"w": "《中论》", "p": "观行品第十三",
            "q": "大聖說空法，為離諸見故；\n若復見有空，諸佛所不化。",
            "l": "T30.1564.0018c16–17"} ] }
```

三栏皆可空，有一栏即可；`src` 用于日后汇总「本书所引经论」。旧注只有 `note` 一个字串，照原样显示，**不强制迁移**。

三栏的分工：**原义**只摆可破之相——小乘、部派、外道于此字此句作何解，不加评断；**观义**出中观正义，依论破之；**串讲**不轻作，只在须把几处教义、几种视角牵合起来、读者方能贯通时用之一二句，兼防读空而堕虚无，不作段落复述，不作「此句是叹佛已办之事」一类套语收束。引书证成己说者入「所引」，自家义解不入。

### 所引的写法

一书一条，四个字段，皆可空：

| 字段 | 内容 | 例 |
|---|---|---|
| `w` | 书名 | `《中論》` |
| `p` | 品名（含品次） | `觀行品第十三` |
| `q` | 原文，换行照录 | `大聖說空法，為離諸見故；……` |
| `l` | 出处与校记 | `T30.1564.0018c16–17` |

- 经文原文与注文同为繁体，读者不必在两种字体间切换（见下〈用字〉）
- `l` 用 `T30.1564.0018c16` 这种「册·经号·页栏行」写法，可直接回查纸本；有异文时把校记接在后面
- 旧数据为纯字符串（如 `"《杂阿含经》"`）者仍照旧显示
- 只写书名、不录原文亦可，此时该条只作书目引用，页上仅出一行书名

### 用字

**网页层一律繁体**（台湾正体）：正文、注文、术语释义、界面文案，无一处简体。增补注文时即以繁体为准；若以简体录入，亦须在提交前转繁，勿使两种字体杂出于一页。

- 七字保留原形：**注、才、峰、面、群、核、朱**。简转繁易误作註、纔、峯、麪、羣、覈、硃；佛典「注疏」從來用「注」，其餘六字亦以通行正體為準
- 「云」亦保留：「論云」不可作「論雲」，而注文引書滿是「經云」「故云」
- 另作三处归一：「衆」→「眾」（随大正藏底本）、「裏」→「裡」、「爲」→「為」、「註」→「注」
- 引号用古籍体：外「」、内『』，与 CBETA 原文和全站文案一致；`src.q`（所引原文）只换引号、不改繁简与用字，免得动了底本
- `text/*.json` 的古籍原文**不动**，一仍底本用字；`sources/*.md` 亦然

### 术语表

`glossary/terms.json` 收名相（`k` 词、`t` 释义、`aka` 异名、`auto` 是否自动加链、`refs` 所据）。注文里凡有释义的术语，首次出现自动加链（同一注只链一次），点开见释义卡；**释义为空者标「待撰」，不加链**，免正文满目虚链。

释义用空行分段，卡片按段渲染，过长则卡内滚动。术语表与注文的详略分工不同：注文求简，只给「可破的对象」；**术语表求备，小乘、部派诸解与中观并列，不为突出中观而略写**——读者点开一词，先看见它在佛教史上的几层意思，再看中观如何取舍。

一条术语也可带「所引」（`src`，字段与注文所引全同：`w` 书名、`p` 品名、`q` 引文、`l` 行号），展开时在所据之前以朱线引出原文，如「滅」条引《中观论疏》「生不自灭，由生故灭」一段。
