# 中觀論 · 印度、中國、日本的中觀學總覽

> 从恒河到长安，再到奈良——一条关于「空」的思想线索，走了约一千八百年。

**在线浏览：<https://rhozero-div.github.io/madhyamaka/>**

以资料库「中观论」文件夹所收二十五部典籍为底本，上溯印度论师的造论与注疏，下及隋唐三论宗的判教与注疏，终至日本南都三论宗的承袭与变形。单文件静态站点，无外部依赖。

## 资料与校勘

- **底本**：资料库「中观论」文件夹 25 部 —— 印度论典 15 部：《中论》《顺中论》《般若灯论释》《百论》《大智度论》《十二门论》《广百论本》《大乘广百论释论》《百字论》《大乘掌珍论》《六十颂如理论》《大乘破有论》《大乘二十颂论》《壹输卢迦论》《十八空论》；汉地撰述 10 部：《中观论疏》《百论疏》《十二门论疏》《大乘玄论》《三论玄义》《二谛义》《净名玄论》《肇论》《肇论疏》《肇论新疏》
- **原文核对**：依大正藏电子文本（CBETA）逐条校出三是偈、八不、「以有空義故」、〈观涅槃品〉末偈等；并经录核对各本卷数（《大乘广百论释论》10 卷、《净名玄论》8 卷、《二谛义》3 卷、《大乘掌珍论》2 卷，余多为一卷本）
- **几处经录更正**：《中观论疏》20 卷、《百论疏》9 卷、《十二门论疏》6 卷（依大正藏经录，非坊间常见的 10／3／3 卷）
- **偈数**：取汉译品题自标合计 456 偈，并注明吉藏审核作 446、古称五百偈
- **日本部分**：人物生卒年取通行之说，以「约」标示，异说随文注出；智藏入唐返日（665–671）、圣宝东南院（905 受施，非新建）、道慈入唐（701 启程、702 抵唐）等，均依较可据之说并注异文
- **外部核对**：除 CBETA 原典外，另与维基百科中、英、日文相关条目（中观学派／Madhyamaka／中観派、三论宗／Sanron、吉藏、智藏、福亮、道慈、圣宝、安澄、玄叡、珍海等）交叉核对年代与异说，采其可据者、驳其可疑者
- **日本撰述**：目录另收大正藏续诸宗部 5 部 —— 安澄《中论疏记》（T65 no. 2255，8 卷，801–806）、玄叡《大乘三论大义钞》（T70 no. 2296，4 卷，830，天长六本宗书之一）、珍海《三论玄疏文义要》（T70 no. 2299，10 卷）、《三论名教抄》（T70 no. 2306，15 卷）、澄禅《三论玄义检幽集》（T70 no. 2300，7 卷，1280）；近代研究著作不入目录，另见年表末段
- **近代研究**：年表末段 23 条依各书初版年（或讲说年）编次，出版年有异说者随文注明（如梶山雄一《空之论理》有 1969 与 1973 两说）

## 本地运行

站点只有一个文件，直接打开即可；如需以 HTTP 方式预览：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000/index.html
```

## 部署

GitHub Pages，`main` 分支根目录直接发布（Settings → Pages → Deploy from a branch → `main` / `(root)`）。根目录 `.nojekyll` 用于跳过 Jekyll 处理。

修改内容后：

```bash
git add -A && git commit -m "更新内容" && git push
```

约一分钟后线上自动更新。
