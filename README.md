# 中觀學 · 印度、中國、日本的中觀傳統

> 从恒河到长安，再到奈良——一条关于「空」的思想线索，走了约一千八百年。

**在线浏览：<https://rhozero-div.github.io/madhyamaka/>**

以大正藏三十部典籍为底本，上溯印度论师的造论与注疏，下及隋唐三论宗的判教与注疏，终至日本南都三论宗的承袭与变形。单文件静态站点，无外部依赖。

- **来源清单**：根目录 `catalog.md` 逐部列大正藏册号、经号、起讫页码与 CBETA 直达链接，共 30 条，供读者复核；网页经论目录下的〈版本出處〉与此表同源

- **《中论疏记》卷次**：底本卷次编号自卷三之末径跳至卷五，卷四、卷六原无卷首标题，非内容残缺；正文二十七品具足，SAT 全文 248 页无缺页。文件内「卷第五（之本）」「卷第五（末）」二题依尾题与品次推定，底本原无
- **命名**：本页题「中观学」，取通名，不隶属任何一宗；英文作 Mādhyamika school，school 为学派而非宗派。梵语 madhyamaka 本义为「中」，mādhyamika 谓持此见者。「中观论」係《中论》详名，出於吉藏（「论有广略二本，略但云中论，广则加以观」），行於汉地，所指本是一书，非派名。各地自称原不相同：印度称中观师、汉地称三论师、日本称三论宗（南都六宗之一，唯一具制度性者）、藏地于宗义中称 dbu ma pa 或深见派。大正藏中「中观派」三字未见，此名为近代学术用语
- **近代研究**：年表末段 23 条依各书初版年（或讲说年）编次，出版年有异说者随文注明（如梶山雄一《空之论理》有 1969 与 1973 两说）
